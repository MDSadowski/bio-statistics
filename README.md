# bio-statistics

Statistical tools for biological datasets.

This repository supports training in statistics and bioinformatics.
The first module computes descriptive statistics for small measurement lists
and is written so it can run on a desktop and on a Casio fx-CG50.

## Contents
- `desktop/biostats.py` — Desktop Python 3.14.7
- `casio/biostats.py` — MicroPython for Casio fx-CG50

## Run on Windows
```powershell
python desktop/biostats.py
